# Встановлення теми КУБ 1.0.0

Розгорнута інструкція для DevOps з Docker/Kubernetes, оновленням, кешами
та відкатом: [DEVOPS.md](DEVOPS.md).

Це окрема тема типу **login** для стандартного **Keycloak 23.0.7**.
Назва в Admin Console: **kub**. Форк Keycloak, збірка Java та доступ до
репозиторіїв КУБ для її використання не потрібні.

Пакет містить розмітку, CSS, українські словники, логотип, фавікон і шрифти.
Базові форми, іконки та скрипти автентифікації успадковуються від штатної
теми `keycloak`, що входить до дистрибутива сервера. Зовнішні CDN не потрібні.

Виберіть **один** спосіб встановлення: JAR або каталог із ZIP. Не залишайте
одночасно дві копії теми `kub` у `providers/` і `themes/`.

## Спосіб 1: JAR

1. Скопіюйте `kub-theme-1.0.0.jar` у `<KEYCLOAK_HOME>/providers/`.
2. Якщо сервер запускається з `--optimized`, перед запуском виконайте
   `bin/kc.sh build` (Windows: `bin\kc.bat build`) зі звичними для вашого
   сервера параметрами збірки, зокрема типом бази даних.
3. Перезапустіть сервер і активуйте тему за інструкцією нижче.

Приклад для вже встановленого сервера Linux:

```bash
cp kub-theme-1.0.0.jar /opt/keycloak/providers/
```

JAR містить лише ресурси теми й `META-INF/keycloak-themes.json`.
Він не додає Java-провайдерів або міграцій бази даних.

## Спосіб 2: каталог із ZIP

Розпакуйте `kub-theme-1.0.0.zip` в окрему робочу папку. Всередині
`kub-theme-1.0.0/` запустіть:

```bash
bash install.sh /opt/keycloak
```

Або вручну скопіюйте папку `kub` до `<KEYCLOAK_HOME>/themes/`.
Результат має виглядати так:

```text
keycloak/
└── themes/
    └── kub/
        └── login/
            ├── theme.properties
            ├── template.ftl
            ├── login.ftl
            ├── messages/
            └── resources/
```

PowerShell після розпакування ZIP:

```powershell
Copy-Item -Recurse .\kub C:\keycloak\themes\
```

Перезапустіть Keycloak, щоб він перечитав шаблони та словники.

## Docker

Приклад окремого образу зі стандартного Keycloak для PostgreSQL:

```dockerfile
FROM quay.io/keycloak/keycloak:23.0.7
COPY --chown=keycloak:keycloak kub-theme-1.0.0.jar /opt/keycloak/providers/
RUN /opt/keycloak/bin/kc.sh build --db=postgres
CMD ["start", "--optimized"]
```

Покладіть JAR поруч із Dockerfile. Підключення до БД, hostname, TLS та
інші параметри запуску залишаються у конфігурації вашого розгортання.
Для іншої СУБД використайте відповідний параметр `--db` під час збірки.

## Активація та мова

1. В Admin Console відкрийте потрібний realm.
2. Перейдіть до **Realm settings → Themes**.
3. У **Login theme** виберіть **kub** і збережіть.
4. У **Localization** рекомендовано ввімкнути Internationalization,
   встановити Supported locales: `uk`, Default locale: `uk`.
5. Відкрийте нову сторінку входу через ваш застосунок або
   `/realms/<realm>/account/`.

Тема також українська при вимкненій локалізації: резервний словник `en`
містить ті самі українські тексти. HTML має `lang="uk"`.
Перевизначення повідомлень у налаштуваннях realm мають пріоритет над пакетом.

Щоб оформити вхід до адмінки, виберіть Login theme `kub` у realm `master`.
Тема не оформлює внутрішні екрани Admin Console, Account Console та листи.
Реєстрація, відновлення пароля, OTP та доступні способи входу визначаються
налаштуваннями realm; тема не вмикає їх самостійно.

## Оновлення та повернення до стандартної теми

При оновленні JAR замініть попередній файл, залишивши в `providers/` лише
одну версію теми `kub`; для `--optimized` повторіть збірку. Після оновлення
перезапустіть Keycloak. У робочому середовищі залишайте кеш тем увімкненим.

Для повернення оберіть штатну Login theme у realm, збережіть, а потім
видаліть установлений JAR або папку `themes/kub` і перезапустіть сервер
(для `--optimized` також повторіть збірку).

## Сумісність

Перевірена версія — **23.0.7**. Пакування використовує стандартний механізм
тем Keycloak, однак це не гарантує сумісності FTL/CSS з усіма майбутніми
версіями. Перед переходом на іншу версію перевірте тему в тестовому
середовищі: вхід, помилку пароля, відновлення, реєстрацію, OTP і мобільний
вигляд. Порівняйте перевизначені шаблони з новими штатними шаблонами.

Для перевірки цілісності завантажених пакетів поруч додається `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
# macOS:
shasum -a 256 -c SHA256SUMS
```

Механізм встановлення описано в [офіційній документації Keycloak](https://www.keycloak.org/ui-customization/themes).
