# КУБ — тема входу Keycloak

Тема для **Keycloak 23.0.7**, успадкована від `keycloak`. Центральна темна
картка з м’яким заокругленням, логотипом, заголовком «Вхід до системи» та
постійними підписами над полями. Окремий текстовий підпис під логотипом і додатковий вступ під заголовком
входу не показуються, щоб зберегти компактність. Допомога розташована під формою всередині
картки; коротке нагадування про захист пароля — під карткою.
Збережено брендинг КУБ: IBM Plex Sans, бірюзові посилання та синю кнопку входу.
Тема повністю українська: словник покриває всі ключі повідомлень
`base/login` Keycloak 23.0.7, окрім назв невикористовуваних мов.

## Готовий пакет для стандартного сервера

Тема не потребує форка Keycloak або коду `kub.ui`. Вона містить усі власні
ресурси та успадковує штатні форми й скрипти від теми `keycloak`.
Версія пакета — у `VERSION`; перевірена версія сервера — **23.0.7**.

Докладне встановлення на сервер, Windows або Docker: [INSTALL.md](INSTALL.md).

Для збірки потрібен лише Python 3.9 або новіший, без зовнішніх бібліотек.
Із кореня репозиторію:

```bash
python3 custom-themes/build-package.py
```

Результат у `custom-themes/dist/`:

- `kub-theme-1.0.0.jar` — встановлення до `providers/` стандартного Keycloak.
- `kub-theme-1.0.0.zip` — каталог `kub`, переносний інсталятор та документація.
- `SHA256SUMS` — контрольні суми обох архівів.
- `INSTALL.md` — інструкція встановлення.

ZIP розпаковується в окрему папку `kub-theme-1.0.0/`; з неї можна виконати
`bash install.sh /path/to/keycloak` або скопіювати `kub` вручну в `themes/`.
Для JAR достатньо самого архіву; штатний Keycloak знаходить тему через
`META-INF/keycloak-themes.json`.

Збірка перевіряє наявність ресурсів, однаковість словників `uk`/`en` і
цілісність архівів. Незмінні вхідні файли дають однакові архіви при повторній
збірці в тому самому середовищі. `dist/` не зберігається в Git; вихідні
файли теми, ліцензії та пакувальник зберігаються разом у `custom-themes/`.

## Локальне встановлення

З кореня репозиторію:

```bash
bash dev/keycloak23/install-theme.sh
```

Скрипт копіює тему в `.kc/dev23/keycloak-23.0.7/themes/kub`.
Повторюйте команду після редагування теми. Keycloak 23.0.7 не дозволяє
посилання на тему поза каталогом `themes/`.
Для іншого дистрибутива передайте його каталог першим аргументом.

У **master → Realm settings → Themes → Login theme** виберіть `kub`.
У **Localization** рекомендовано увімкнути локалізацію, залишити `uk` і вибрати `uk`
як стандартну мову. Якщо локалізацію вимкнено, тема також показує українські
тексти через резервний словник `messages_en.properties`: Keycloak у цьому
випадку обирає `en`. Перемикача мов немає, HTML має `lang="uk"`.
Admin theme залишається без змін: тема оформлює вхід до
адмінки, а не її внутрішні екрани. Міграцій схеми БД не потрібно.

На час розробки додайте до `kc.sh start-dev`:

```text
--spi-theme-static-max-age=-1 --spi-theme-cache-themes=false --spi-theme-cache-templates=false
```

Після перезапуску сервера зміни CSS/FTL видно після оновлення сторінки.
Повна збірка Java для редагування теми не потрібна.

## Що редагувати

- `kub/login/resources/css/kub.css` — кольори (CSS-змінні `--kub-*`), шрифти, розміри, адаптивність.
- `kub/login/resources/fonts/` — самохостинг IBM Plex Sans (400/500/600/700, woff2), скопійовано з `kub.ui/public/fonts`.
- `kub/login/resources/img/` — актуальне лого `kub-logo-hq.webp` (1024×1024, lossless, прозорий фон), підготовлене програмно з наданого користувачем PNG без генеративного перемальовування; фавікон із `kub.ui/public`.
  Розмір лого: 328.509 px на desktop, 267.674 px на mobile; на найвужчих екранах обмежений шириною вмісту картки. М’який радіальний фон відділяє темні деталі емблеми від картки. Залишено лише напис усередині самого зображення; окремий текстовий підпис прибрано. Основний текст — приглушений сіро-блакитний `#c8ced8`.
- `kub/login/template.ftl` — спільна картка, лого, допомога та необов’язковий вступ `displayLoginIntro` для форми входу.
- `kub/login/login.ftl` — розмітка форми входу.
- `kub/login/messages/messages_uk.properties` — українські тексти, включно з помилками й успадкованими формами.
- `kub/login/messages/messages_en.properties` — ідентична українська копія для резервної мови Keycloak. Після зміни текстів синхронізуйте: `cp custom-themes/kub/login/messages/messages_uk.properties custom-themes/kub/login/messages/messages_en.properties`.

Базові українські переклади адаптовано з community-словника Keycloak;
шлях та ревізію джерела зазначено на початку обох файлів (Apache-2.0).
Перевизначення текстів у налаштуваннях realm мають пріоритет над темою.

Палітра походить із `kub.ui` (`src/shared/styles/tokens.ts`,
`src/pages/home/styles/homePagePalette.ts`); поверхні й контраст адаптовано
для центральної картки. При зміні бренд-палітри в `kub.ui` перегляньте
`--kub-*` змінні тут.

FTL-шаблони базуються на `theme/base/login` з офіційного тегу 23.0.7
(Apache-2.0, див. кореневий LICENSE.txt). Під час оновлення Keycloak порівняйте
їх із новими батьківськими шаблонами, особливо параметри форм і скрипти входу.
Відновлення пароля, OTP та інші сторінки використовують успадковані форми.
Посилання на реєстрацію/відновлення відображаються лише коли їх дозволено realm.

## Синхронізація з upstream

Брендинг, пакувальник і переносний інсталятор зберігаються в `custom-themes/`;
`dev/keycloak23/install-theme.sh` лише викликає інсталятор для локального сервера.
Не редагуйте вбудовані `themes/src`, Java-код або
батьківську тему `keycloak` заради брендингу. Копії в `.kc/` ігноруються Git.
Це ізолює наші правки під час синхронізації форка з upstream.

Сумісність теми з майбутніми версіями потребує перевірки: після оновлення
порівняйте `template.ftl` і `login.ftl` з новою версією, перевірте CSS-класи
та додайте нові ключі повідомлень до обох словників. На окремому тестовому
realm перевірте вхід, неправильні дані, показ пароля, відновлення, реєстрацію,
OTP та мобільну ширину. Наявність окремої теми не означає автоматичної
сумісності FTL між усіма версіями Keycloak.

Для розгортання скопіюйте каталог `kub` у `themes/` дистрибутива або образу
Keycloak. У розгорнутому середовищі залишайте кеш тем увімкненим.
Паролі, дампи БД і локальний дистрибутив у цю папку не додавайте.
